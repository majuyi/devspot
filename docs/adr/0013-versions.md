# 0013 · Prisma 7 and TypeScript 5.9; majors by ADR

**Context.** Prisma 8 is a release candidate; TypeScript 7 (Go compiler) is newly released and the ecosystem's type packages are not verified against it.

**Decision.** Pin Prisma 7.10 and TypeScript 5.9.x. Upgrade either only through an ADR after M2.

**Consequences.** Stable ground for the executor. Two known upgrades queued.

**Status.** Accepted, 2026-09-18.
