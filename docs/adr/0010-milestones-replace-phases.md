# 0010 · Milestones with gates replace the phase plan

**Context.** The phase plan optimised for one maintainer keeping scope tiny. Dami wants a Google-or-Apple quality bar and specs precise enough for Opus to execute.

**Decision.** Six milestones (M0 to M5) with task lists sized per session and a measurable gate each, in docs/08-milestones.md. Registry research runs in parallel as a non-code track.

**Consequences.** Code starts at M0. Quality is enforced by gates, not by keeping the product small.

**Status.** Accepted, 2026-09-18.
