# 0015 · Apache-2.0

**Context.** Apache-2.0 (CLIST's choice, maximum adoption) versus AGPL (stops a commercial board taking the pipeline wholesale).

**Decision.** Apache-2.0, proposed. The data itself is facts and is published without restriction; the registry is CC0.

**Consequences.** Universities and other projects can embed freely. A commercial copy is possible and accepted as the cost of adoption.

**Status.** Proposed, 2026-09-18. Dami confirms before the first public push.
